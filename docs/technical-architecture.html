05 · Security model

Authorization lives with the data.

Publishable browser key hanya membuka Data API; akses aktual tetap ditentukan oleh session JWT, RLS ownership/assignment policy, dan RPC yang memeriksa actor.

01

Verified identity

Supabase Auth menjadi satu-satunya identity source. Session dipersist dan diperbarui oleh SDK.

02

RLS by default

Owner, assigned reviewer, admin, dan public publication memperoleh row visibility berbeda.

03

Trusted commands

Transition, assignment, submission, order creation, dan message command lewat RPC terkontrol.

04

Storage policies

Chat images memakai private path dan signed URL; catalog media dikelola staff.
